# Taste
- Follows a complete end-of-task loop for verified fixes: commit the change, push to the main branch, then close the related issue (with a summary comment) — all in one go, without waiting for a separate reminder to close the issue. Explicitly prompts the agent to do this when ready, repeating the instruction even if the work already finished ("silahkan commit dan push lalu close issue terkait", "oke silahkan commit dan close issue terkait") and expects the agent to verify state and report back if nothing is left. Confidence: 0.9
- Keeps production deployment out of the routine task loop: commit/push only trigger CI, and deploy stays an explicit manual dispatch ("jangan deploy"). Confidence: 0.7
- Communicates in Bahasa Indonesia (Indonesian); expects the agent to respond in Indonesian as well. Confidence: 0.9
- Steers sessions with terse prompts ("oke silahkan commit dan push lalu close issue terkait", "/cmd -yolo", "resume", "continue") and expects the agent to work autonomously through the full task loop without intermediate check-ins. Confidence: 0.65
- When asked to explain an issue ("masalahnya apa sih, coba jelasin"), prefers a plain-language walkthrough — root cause first, then the consequences (with concrete real-world impact), then the fix — using short, structured sections and avoiding jargon, rather than a purely technical changelog recap. Confidence: 0.55
- Treats verification as part of the task, not optional: before committing, run the whole test suite (`php artisan test`), the formatter in check mode (`./vendor/bin/pint --test`), and the heavyweight PostgreSQL concurrency gate (`composer test:concurrency-gate`) — each configured via env vars/artefact dirs — and report the pass counts as evidence. Confidence: 0.7
- Keeps a documented domain model: introducing a new domain concept means updating the `CONTEXT.md` glossary (including an "_Avoid_:" list of rejected synonyms), the `docs/agents/codebase.md` map/table/test index, and adding a numbered ADR under `docs/adr/`. Confidence: 0.65
- Commit style: conventional-commit subject with the issue number in parentheses, a body explaining each decision group, an explicit "Evidence:" section with the test/formatting run results, and a `Co-authored-by:` trailer. Confidence: 0.6
